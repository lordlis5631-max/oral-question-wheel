# Колесо устного опроса — версия для GitHub Pages

Готовый статический тренажёр русского языка для 7А, 7Г, 8А, 8Б, 8Г. Сборка и установка зависимостей не нужны. Банк содержит 130 вопросов с короткими ответами, развёрнутыми объяснениями и полными устными разборами.

## Запуск

Распакуйте архив и откройте `index.html` в современном браузере. Все файлы сайта должны оставаться вместе. Для постоянной работы рекомендуем HTTPS-адрес GitHub Pages: поведение сохранения на адресах `file://` различается в браузерах.

## Размещение на GitHub Pages

Публикуйте только после согласия владельца. Обычный сайт GitHub Pages общедоступен, включая банк ответов в исходных файлах. У приложения нет авторизации. Приватный репозиторий сам по себе не делает сайт приватным.

1. Создайте отдельный репозиторий, например `oral-question-wheel`. Не используйте репозиторий другого проекта.
2. Загрузите в корень `index.html`, `styles.css`, `app.js`, `core.js`, `bank.js` и `.nojekyll` из этого архива. Не загружайте резервные копии, Excel с оценками или списки учеников.
3. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, затем `Save`.
4. Дождитесь успешного развёртывания. Откройте фактический адрес, показанный GitHub в разделе Pages, и проверьте вращение и запись оценки.

Пути к файлам относительные, поэтому приложение работает в подпапке репозитория. Домен и имя пользователя в коде не зашиты. Рабочая ссылка появляется только после включения Pages; этот архив сам ничего не публикует.

## На уроке

1. Выберите один или несколько классов и уровней сложности. Разделы можно ограничить в настройках.
2. В настройках отметьте закреплённые темы отдельно для каждого 7-го класса. При выборе поздней темы включаются предыдущие; при выключении ранней отключаются следующие. Это не меняет историю оценок.
3. Введите имя, укажите фактический класс ученика и запустите колесо.
4. Выслушайте устный ответ, нажмите «Далее — показать ответ», затем поставьте 2–5. Тренажёр не распознаёт речь и не выставляет оценку автоматически.
5. Можно продолжить с тем же учеником или перейти к следующему. Возврат к колесу и перезагрузка не теряют незавершённый вопрос.
6. Пропуск сохраняется без оценки. Вопрос считается заданным; на средний балл пропуск не влияет.
7. В результатах доступны все ответы, сводка по ученикам, исправление имени/класса/оценки и необязательная итоговая оценка учителя. Ответ можно удалить крестиком × рядом с «Изменить». Удаление требует подтверждения; в течение 12 секунд доступна отмена. Статистика пересчитывается сразу, а заданный вопрос остаётся исключённым до конца занятия. Порядок ответов переключается между сортировкой по классам 7А → 7Г → 8А → 8Б → 8Г и временем (новые сверху); внутри каждого класса новые ответы идут первыми. Экспорт Excel следует выбранному порядку.
8. Новое занятие сбрасывает исключения вопросов и сохраняет предыдущие занятия в архиве.

У разделов, в которых остались подходящие вопросы, равные шансы. Внутри выбранного раздела равновероятно выбирается один из доступных выбранных уровней, затем вопрос этого уровня. Поэтому разные карточки во всём банке не обязаны иметь одинаковую вероятность.

Повторы исключаются по паре «занятие + фактический класс». Один вопрос может быть задан в 7А и 7Г в одном занятии. Смена фильтров не возвращает уже заданные вопросы. При исправлении ошибочно указанного класса карточка исключается в обоих классах, чтобы не повторить её случайно.

## Данные и перенос

Данные сохраняются только в локальном хранилище браузера. На сервер не отправляются. Автоматической синхронизации компьютеров, аккаунтов и облачного журнала нет. В другом браузере, профиле или на другом адресе будет отдельная история. Очистка данных сайта может удалить историю; в приватном режиме сохранность после закрытия не гарантируется.

- `Результаты → Скачать Excel` выгружает выбранное занятие и класс в настоящий `.xlsx` с листами «Ответы» и «По ученикам». Оценки и средние записываются числами. Текстовые поля не выполняются как формулы.
- `Настройки → Скачать резервную копию` выгружает полную историю, учеников, изученные темы и текущий вопрос в `.json`.
- `Восстановить из копии` проверяет формат и предлагает заменить текущие данные. Перед заменой запускается скачивание текущей копии. Убедитесь, что браузер разрешил загрузку. Максимальный размер импортируемой копии — 5 МБ.
- Excel служит отчётом; для восстановления используйте JSON. Храните копии с именами и оценками в месте, доступном только учителю.

При ошибке сохранения появляется заметная плашка: работа продолжается в памяти, но перед закрытием требуется скачать копию. Рекомендуется работать в одной вкладке. При обнаружении изменений в другой вкладке нужно повторить действие с обновлёнными данными.

## Состав банка

46 базовых, 56 углублённых, 28 продвинутых вопросов. Шесть разделов: фонетика, морфемика, лексикология, морфология, синтаксис и пунктуация, орфография. Есть чередующиеся корни, Н/НН в прилагательных и причастиях, полные морфологические, морфемные и синтаксические разборы.

Для 7-го класса по умолчанию доступны 81 вопрос при выборе всех уровней; после закрепления §§ 23–25 — 99. После более поздних этапов о причастии и деепричастии — 105. Для 8-го класса доступно 130. Уровень сложности сам по себе не открывает ещё не изученные темы. При начальных уровнях 1–2 цифры меньше: это нормальный результат совместного применения фильтров.

Банк подготовлен для указанного учителем этапа: 7-й класс начинает причастия и причастный оборот; 8-й класс изучил подлежащее и переходит к сказуемым. Планы синтаксических разборов не требуют ещё не изученных категорий 8-го класса. Допуск по темам необходимо соотносить с фактическим темпом конкретного класса.

## Для разработчика

Приложение не использует внешние CDN, аналитику, сетевые API, сборщик или сторонние пакеты. `core.js` отвечает за выбор, допуск, сессии, проверку резервных копий и формирование XLSX; `app.js` — за интерфейс и локальное сохранение; `bank.js` — за банк. Все файлы развёртывания находятся в корне архива.

В папке `checks` находится проверка логики. Запуск из корня распакованного архива: `node checks/checks.cjs`. Для этого нужен Node.js; посетителям сайта он не нужен. Проверка создаёт только тестовый файл `checks/check-export.xlsx`.
