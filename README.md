# Колесо устного опроса — версия для GitHub Pages

Готовый статический тренажёр русского языка для 7А, 7Г, 8А, 8Б, 8Г. Сборка и установка зависимостей не нужны. Банк содержит 160 вопросов с короткими ответами, развёрнутыми объяснениями и полными устными разборами.

## Запуск

Распакуйте архив и откройте `index.html` в современном браузере. Все файлы сайта должны оставаться вместе. Для постоянной работы рекомендуем HTTPS-адрес GitHub Pages: поведение сохранения на адресах `file://` различается в браузерах.

## Размещение на GitHub Pages

Публикуйте только после согласия владельца. Обычный сайт GitHub Pages общедоступен, включая банк ответов в исходных файлах. У приложения нет авторизации. Приватный репозиторий сам по себе не делает сайт приватным.

1. Создайте отдельный репозиторий, например `oral-question-wheel`. Не используйте репозиторий другого проекта.
2. Загрузите в корень `index.html`, `styles.css`, `app.js`, `core.js`, `bank.js` и `.nojekyll` из этого архива. Не загружайте резервные копии, Excel с оценками или списки учеников.
3. В `Settings → Pages` выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, затем `Save`.
4. Дождитесь успешного развёртывания. Откройте фактический адрес, показанный GitHub в разделе Pages, и проверьте вращение и запись оценки.

Пути к файлам относительные, поэтому приложение работает в подпапке репозитория. Домен и имя пользователя в коде не зашиты. Рабочая ссылка появляется только после включения Pages; этот архив сам ничего не публикует.

## На уроке

1. Выберите один или несколько классов и уровней сложности. Разделы можно ограничить в настройках.
2. В настройках отметьте закреплённые темы отдельно для каждого 7-го класса. При выборе поздней темы включаются предыдущие; при выключении ранней отключаются следующие. Это не меняет историю оценок.
3. Введите имя, укажите фактический класс ученика и запустите колесо.
4. Выслушайте устный ответ, нажмите «Далее — показать ответ», затем поставьте 2–5. Тренажёр не распознаёт речь и не выставляет оценку автоматически.
5. Можно продолжить с тем же учеником или перейти к следующему. Возврат к колесу и перезагрузка не теряют незавершённый вопрос.
6. Пропуск сохраняется без оценки. Вопрос считается заданным; на средний балл пропуск не влияет.
7. В результатах доступны все ответы, сводка по ученикам, исправление имени/класса/оценки и необязательная итоговая оценка учителя. Ответ можно удалить крестиком × рядом с «Изменить». Удаление требует подтверждения; в течение 12 секунд доступна отмена. Статистика пересчитывается сразу, а заданный вопрос остаётся исключённым до явного возврата в настройках. Порядок ответов переключается между сортировкой по классам 7А → 7Г → 8А → 8Б → 8Г и временем (новые сверху); внутри каждого класса новые ответы идут первыми. Экспорт Excel следует выбранному порядку.
8. Урок создаётся автоматически по дате и фактическому классу первого ответа. Новый урок сохраняет исключения вопросов. Для второго урока того же класса в этот день есть кнопка «Ещё один урок сегодня». Пустые архивные уроки очищаются без потери оценок; незавершённые вопросы сохраняются.

У разделов, в которых остались подходящие вопросы, равные шансы. Внутри выбранного раздела равновероятно выбирается один из доступных выбранных уровней, затем вопрос этого уровня. Поэтому разные карточки во всём банке не обязаны иметь одинаковую вероятность.

Повторы исключаются по фактическому классу между уроками до явного возврата вопросов. Один вопрос может быть задан в 7А и 7Г в одном занятии. Смена фильтров не возвращает уже заданные вопросы. При исправлении ошибочно указанного класса карточка исключается в обоих классах, чтобы не повторить её случайно.

## Показ с проектора

На экране занятия колесо увеличено и подстраивается под высоту окна. На широком экране кнопка «Режим проектора» рядом с выбором разделов открывает крупный вид: верхняя навигация и заголовок скрываются, колесо занимает максимально доступную площадь, а выбор ученика и запуск остаются слева. Выйти можно кнопкой «Обычный вид» или Esc. При переходе к настройкам и результатам обычный вид включается автоматически. Для дополнительного увеличения можно включить полноэкранный режим браузера клавишей F11.

## Данные и перенос

Данные сохраняются только в локальном хранилище браузера. На сервер не отправляются. Автоматической синхронизации компьютеров, аккаунтов и облачного журнала нет. В другом браузере, профиле или на другом адресе будет отдельная история. Очистка данных сайта может удалить историю; в приватном режиме сохранность после закрытия не гарантируется.

- `Результаты → Скачать Excel` выгружает выбранный период, урок и класс в настоящий `.xlsx` с листами «Ответы», «По ученикам» и «Для журнала». Оценки и средние записываются числами. Текстовые поля не выполняются как формулы.
- `Настройки → Скачать резервную копию` выгружает полную историю, учеников, изученные темы и текущий вопрос в `.json`.
- `Восстановить из копии` проверяет формат и предлагает заменить текущие данные. Перед заменой запускается скачивание текущей копии. Убедитесь, что браузер разрешил загрузку. Максимальный размер импортируемой копии — 25 МБ.
- Excel служит отчётом; для восстановления используйте JSON. Храните копии с именами и оценками в месте, доступном только учителю.

При ошибке сохранения появляется заметная плашка: работа продолжается в памяти, но перед закрытием требуется скачать копию. Рекомендуется работать в одной вкладке. При обнаружении изменений в другой вкладке нужно повторить действие с обновлёнными данными.

## Состав банка

89 базовых, 47 углублённых, 24 продвинутых вопросов. Шесть разделов: фонетика, морфемика, лексикология, морфология, синтаксис и пунктуация, орфография. Есть чередующиеся корни, Н/НН в прилагательных и причастиях, полные морфологические, морфемные и синтаксические разборы.

Для 7-х классов начальная настройка — до § 25 включительно (121 карточка при всех уровнях), для 8-х — повторение 7 класса и словосочетание (153 карточки). После включения § 14 восьмым классам доступны 160 карточек. Все настройки индивидуальны для буквы класса; ограничения по сложности и разделам применяются отдельно.

Банк подготовлен для указанного учителем этапа: 7-й класс начинает причастия и причастный оборот; 8-й класс изучил подлежащее и переходит к сказуемым. Планы синтаксических разборов не требуют ещё не изученных категорий 8-го класса. Допуск по темам необходимо соотносить с фактическим темпом конкретного класса.

## Для разработчика

Приложение не использует внешние CDN, аналитику, сетевые API, сборщик или сторонние пакеты. `core.js` отвечает за выбор, допуск, сессии, проверку резервных копий и формирование XLSX; `app.js` — за интерфейс и локальное сохранение; `bank.js` — за банк. Все файлы развёртывания находятся в корне архива.

В папке `checks` находится проверка логики. Запуск из корня распакованного архива: `node checks/checks.cjs`. Для этого нужен Node.js; посетителям сайта он не нужен. Проверка создаёт только тестовый файл `checks/check-export.xlsx`.

Версия: 1.9, 7 ноября 2026 года.

Утверждённая переклассификация: изменены уровни 56 карточек, сохранены 74. Полный прозрачный разбор относится к базовому уровню. Формулировки, ответы, номера и допуск по изученным темам сохранены.

Добавлены 30 авторских карточек № 131–160: контекстный анализ, проверка ложных объяснений, морфемные и морфологические разборы, преобразование словосочетаний и комплексная пунктуация. Все прежние 130 карточек сохранены.

Вкладка «Банк вопросов»: поиск по номеру, словам и теме, фильтры по разделу, уровню, классу и включённости. Показаны разбор, типичная ошибка и основания уровня. Выключенные карточки исключены из новых вращений во всех классах этого браузера; настройки сохраняются в резервной копии. Текущий вопрос и результаты не удаляются. Старые резервные копии без списка отключений принимаются.

Оформление 1.8: компактные фильтры и раскрываемые пояснения, цветовые маркеры разделов, отдельные подписи статуса, усиленная иерархия карточек, блок краткого ответа и читаемый разбор, адаптивная панель оценок. Сценарий опроса и данные сохранены.

Подробный выбор тем 1.9: 26 переключателей в группах повторения 5–6, причастия, следующих тем 7 класса и синтаксиса 8 класса. Профили перенастраиваются один раз по указанному учителем текущему этапу; оценки, ученики, история и отключения сохраняются. Настройки тем включены в резервную копию. Тема без карточек помечена явно. Включаются только необходимые предпосылки, при выключении закрываются зависимые темы.

## Версия 2.0 — текущая тема и тематические банки

Общий опрос сохраняет прежние 160 карточек. Отдельный режим «Текущая тема» использует 108 утверждённых карточек: 55 по причастному обороту и 53 по подлежащему. Условия доступа по классу, пройденным темам, уровням и отключениям применяются вместе. Фильтры разделов действуют только в общем опросе. История и списки заданных вопросов общие для режимов и независимы для каждой буквы класса.

Для запуска: «Занятие» → «Режим опроса» → «Текущая тема» → тема → уровни → класс ученика и имя → «Выбрать вопрос». Если тема закрыта, её можно явно отметить как пройденную для выбранной буквы класса. Выбор продвинутого уровня сам по себе тему не открывает.

В банке учителя добавлены фильтры набора, темы и творческого формата, поиск по устойчивым ID PO7-… и SUB8-…. На карточках творческих заданий после ответа показаны пример решения, обязательные пункты, допустимость иных решений и дополнительные вопросы учителя. Ответ дополнительного вопроса раскрывается отдельно.

Старые резервные копии и localStorage oral-wheel-pages-v1 сохраняют совместимость; исходные RU-ID не менялись. Тематические ID сохранены из согласованного банка версии 1.2.


## Версия 2.1 — оформление и проведение опроса

Настройки занятия вынесены в сворачиваемую панель над опросом. В сводке видны классы, режим/тема и выбранные уровни. Кнопка «Готово — к опросу» сворачивает панель; выбор ученика и запуск остаются в отдельном компактном блоке. При первом вопросе панель сворачивается автоматически. Её состояние запоминается в текущей вкладке через sessionStorage, отдельно от истории оценок.

Модуль question-view.js оформляет длинные условия по шагам, выделяет действия и помещает длинные цитаты в отдельные плашки. Исходные условия, ответы и уровни не изменяются. Цитаты и уже имеющаяся нумерация сохраняются; HTML экранируется. Тестируется сохранность всего текста 268 карточек.

Режим проектора доступен в самой карточке и в тематическом опросе. Навигация убирается, шрифт увеличивается, для особенно длинных условий используется более компактный размер. Ответ открывается только кнопкой «Далее», оценки доступны после открытия. Выход — кнопкой «Обычный вид» или Esc; после оценки и возврата к выбору интерфейс возвращается в обычный вид.

Проверка: node checks/checks.cjs — 36 проверок; дополнительно проверены в браузере обычное колесо, тематический опрос, сохранение свёрнутых настроек, режим проектора и выставление оценки.


## Версия 2.2 — уроки и история вопросов

Оценки распределяются по отдельным урокам с датой и классом. История заданных вопросов хранится независимо для 7А, 7Г, 8А, 8Б и 8Г и не сбрасывается при новом уроке. Первый ответ дня автоматически создаёт урок; для второго урока в тот же день используйте «Ещё один урок сегодня». Дата определяется местным временем браузера; начатый до полуночи вопрос остаётся на исходном уроке.

«Настройки → Повторение» позволяет явно вернуть вопросы выбранного класса: весь банк, общий опрос либо одну тему в обоих режимах. Оценки и отключённые карточки сохраняются. Незавершённый вопрос остаётся исключённым. Удаление записи ответа не возвращает вопрос в колесо.

В результатах доступны сегодня, текущая неделя (с понедельника), все даты и произвольный период, фильтр класса и выбор урока. Вид «Для журнала» показывает всех учеников и все отдельные оценки по датам без усреднения. Excel включает такую же таблицу третьим листом.

Старые оценки сохраняются. При первом открытии переносятся последние непустые списки исключений каждого класса и все незавершённые вопросы; давние циклы вопросов не объединяются. Резервные копии включают независимую историю вопросов. Поддерживаются старые копии без неё.

Проверка: 46 автоматических проверок, браузерные сценарии уроков/классов, редактирования, повторения и журнала; проверка трёх листов XLSX через openpyxl.
