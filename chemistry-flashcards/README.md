# Карточки по неорганической химии

Простой тренажёр с переворотом карточек — **без ввода ответов, тестов, оценок и автоматической проверки**.

## Содержимое

- **152 карточки с веществами**: оксиды, кислоты, основания, соли, другие вещества. Два направления: «формула → название» и «название → формула».
- **106 карточек с реакциями**: сначала исходные вещества и условия, после переворота — сбалансированное уравнение и словесное описание продуктов.
- Фильтр по темам, перемешивание колоды, переходы вперёд/назад, сохранение положения в браузере.
- Управление: клик по карточке или пробел — перевернуть; ←/→ — перейти.

## Источники

Карточки составлены по трём предоставленным учебным PDF: `неорганика 1.pdf`, `Neorganika.pdf`, `Неорганическая хими 2.pdf`. Использованы типовые формулы и уравнения; в банке сохранены условия, когда они принципиальны. Каждое уравнение проверено программно на атомный баланс. Предусмотрено упрощение записи некоторых равновесий (например, CO₂ и H₂O), обозначенное в подсказке.

## Открытие

Приложение находится в каталоге `chemistry-flashcards/`, не затрагивая основной тренажёр русского языка. Если в этом репозитории GitHub Pages развёрнут из ветки `main` и корневой папки, адрес сайта:

https://lordlis5631-max.github.io/oral-question-wheel/chemistry-flashcards/

Если GitHub Pages ещё не активирован, владелец может выбрать **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Включать Pages не обязательно для хранения кода, но без Pages браузерная ссылка работать не будет.

Приложение статическое: `index.html`, `app.js`, `bank.js`. Никакие персональные данные не загружаются на сервер. Положение в колоде хранится только в `localStorage` данного браузера.
